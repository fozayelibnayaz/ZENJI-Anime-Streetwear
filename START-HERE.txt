UPDATE YOUR REPO (fozayelibnayaz/ZENJI-Anime-Streetwear)
  1. Unzip this file into an empty folder on your computer.
  2. In your clone of the repo, DELETE the old docs folder first:
       rm -rf docs
  3. Copy EVERYTHING from the unzipped folder into the repo root
     (source files + the new docs folder). Keep the hidden .git folder.
  4. git add -A
     git commit -m "ZENJI complete project, chapters 01-06"
     git push origin main
  5. Repo Settings -> Pages: Source = Deploy from a branch,
     Branch = main, Folder = /docs. Save.
  6. Wait ~1 minute, then HARD REFRESH the site (Ctrl/Cmd + Shift + R).
